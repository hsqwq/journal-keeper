# jk — Journal Keeper

AI 帮你整理的终端记事本 / 任务日志。你只管说一句话，jk 负责记下、归类、排好。

```
  周期 [2 项]
    6. ↻ 跑步          每周一 08:00 · 下次 周一 08:00（还剩 5天）
    7. ↻ 上数值分析课  每周二、四 16:00 · 下次 后天 16:00（还剩 46小时）

  作业 [1/4]
    5. ☐ 交报销单 !!         昨天 · 已逾期 17小时
    2. ☐ 作业 a !        明天 15:00 · 还剩 21小时
    3. … 实验报告 进行中      10月20日 · 还剩 7天
    1. ✔ 数值分析作业

  想法 [笔记]
    4. ● 试试用 rich 做界面

  25% 完成 · 1 完成 · 1 进行中 · 2 待办 · 1 笔记
```

## 安装

需要 [uv](https://docs.astral.sh/uv/)。

```sh
uv tool install -e ~/Projects/jk
```

## 配置

第一次运行 `jk` 会生成 `~/.jk/.env`，打开填上 Key：

```sh
JK_API_KEY=sk-xxxx                      # 必填，DeepSeek API Key
JK_BASE_URL=https://api.deepseek.com    # 请求地址
JK_MODEL=deepseek-flash                 # 模型
JK_ARCHIVE_AFTER_DAYS=1                 # 完成后几天归档；1=第二天，0=不归档
JK_TIMEOUT=60                           # AI 超时（秒）
```

- Key 在 <https://platform.deepseek.com/api_keys> 创建。
- 也认 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`。
- 终端里设置同名环境变量会覆盖 `.env`。
- 想换数据目录：设置环境变量 `JK_HOME=/某个/目录`。

## 用法

| 命令 | 作用 |
| --- | --- |
| `jk` | 列出所有记事本 |
| `jk a <一句话>` | 交给 AI 处理（可以带图片路径） |
| `jk a` | 打开输入框，可以粘贴大段文字和截图 |
| `jk c <编号…>` | 标记完成；再按一次取消完成（不走 AI） |
| `jk t [天数]` | 时间线：回顾最近几天 + 即将到期（默认 7 天） |
| `jk undo` | 撤销上一次改动（可连续撤销，最多 50 步） |
| `jk h` | 中文帮助 |

### `jk a` 能听懂的话（举例）

```sh
jk a 有个任务，明天三点截止，要求我完成作业a
jk a 任务2已完成
jk a 作业a已经完成了
jk a 实验报告开始做了
jk a 报销单很急，改成今晚
jk a 记一下：图书馆周六不开门
jk a 每周一早上八点跑步
jk a 工作日早上七点半背单词
jk a 明天要交什么
jk a 帮我把记事本整理一下
```

### 周期（每天 / 工作日 / 每周几 / 每月几号）

说「每周一早上八点跑步」「每月 15 号交房租」这类会重复的事，jk 会把它放进最上面的「周期」分组：

- 只占一行，永远显示**下一次**的时间；过了时间自动跳到下一次。
- 不用打卡，也不会逾期。`jk c` 对周期条目无效。
- `jk t` 的「即将到期」里会列出接下来每一次。
- 没说周几（「每周下午四点上课」）时，AI 会问你是哪几天。
- 改时间：`jk a 跑步改到每周三`；不要了：`jk a 不跑步了`。
- 支持：每天、工作日、每周几（可多天）、每月几号，可带钟点。暂不支持隔周、单双周、每年。

### 粘贴文字和截图

先敲 `jk a` 回车，打开输入框：

| 按键 | 作用 |
| --- | --- |
| `Ctrl+Shift+V` | 粘贴文字。长文字显示成 `[粘贴文字 #1 · 20行]` |
| `Ctrl+V` | 粘贴剪贴板里的截图（显示 `[图片 #1]`），也能粘文字 |
| 回车 | 发送 |
| `Ctrl+C` | 取消 |

- 可以边打字边粘贴，比如：`这是本周作业 [图片 #1]`。
- 不想发某一项，就把它的 `[…]` 删掉。
- 不写说明直接发送，AI 会把里面每件要做的事都提取成任务。
- 也可以不开输入框，直接带图片路径：`jk a 这是通知 ~/Pictures/通知.png`。
- 读剪贴板需要 `wl-clipboard`（Wayland）或 `xclip`（X11）。

**防误发密钥**：内容里像 API Key、密码、私钥时，jk 会先停下问你，输入 `y` 才发送。

### 小提示

- 一句话里可以有好几件事。
- 自动去重：发了两张内容有重叠的图，已有的事不会再加一遍，显示成 `≈ 已存在`；有新信息（比如截止改了）会直接改原来那条。真想再加一个一样的，就明说「再加一个」。
- 对不上号时，AI 会反问并给编号选项：输入数字选，或直接打字回答，直接回车取消。
- 改完会列出改了什么。改错了就 `jk undo`。

### 图标

| 图标 | 意思 |
| --- | --- |
| `☐` | 待办 |
| `…` | 进行中 |
| `✔` | 已完成 |
| `●` | 笔记 |
| `↻` | 周期 |
| `!` / `!!` | 重要 / 紧急 |
| `≈ 已存在` | 和已有条目重复，没有再添加 |

截止时间：红色 = 已逾期，黄色 = 24 小时内，青色 = 更晚。颜色是写死的固定色，不受终端主题影响；想改颜色只改 `src/jk/theme.py` 里的 `PALETTE`。

## 数据在哪

```
~/.jk/
  .env          配置（明文，权限 600）
  jk.json       数据格式版本号
  notebooks/    记事本，一本一个 .md
  archive/      已归档的完成任务
  history/      撤销用的快照
  pastes/       输入框里粘贴的内容（发送后立即删除）
  backups/      升级前的自动备份
```

记事本是普通 Markdown，可以用 Obsidian 或任何编辑器打开、手改。手写的 `- [ ] xxx` 会被自动收编。格式见 [docs/data-format.md](docs/data-format.md)。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 「还没配置 API Key」 | 在 `~/.jk/.env` 填 `JK_API_KEY=` |
| 「API Key 无效」 | Key 填错或过期，去 DeepSeek 后台重建 |
| 「找不到模型或地址」 | 检查 `JK_MODEL`、`JK_BASE_URL` |
| 「读写文件失败」 | 数据目录没有写权限，修权限或用 `JK_HOME` 换目录 |
| 「数据格式比当前 jk 新」 | 你在用旧版 jk，先升级 |
| 「读不了剪贴板」 | 安装 `wl-clipboard` 或 `xclip` |
| 「好像有 API Key」 | 内容里有疑似密钥；确认没问题再输入 `y` |
| 发图片报 HTTP 400 | 当前 `JK_MODEL` 不支持图片，换 `deepseek-flash` |
| 编号变了 | 完成的任务归档后，编号会让给新任务，保持编号短小 |
