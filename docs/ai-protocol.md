# AI 协议

## 流程

1. `jk a <一句话>`：程序把「当前时间、未来几天的日历、全部记事本、最近 30 天归档」打包成 JSON，连同你的话发给 AI。
2. AI 只返回一个 JSON 对象（使用 DeepSeek 的 JSON 模式），程序不让 AI 直接写文件。
3. 程序逐条校验；有一条不合法就整份作废，把错误告诉 AI 让它改正。
4. 校验通过 → 先拍快照（供 `jk undo`）→ 执行 → 显示改动。
5. 反问、纠错合计最多 6 轮，超过就放弃，**不做任何改动**。

提示词全文在 `src/jk/ai.py` 的 `SYSTEM_PROMPT`。

## 附件（粘贴文字 / 图片）

- 粘贴的长文字放在用户消息里，用 `<<<` `>>>` 包起来，并标上来源（如「粘贴文字 #1 · 20行」）。
- 有图片时，用户消息改成多模态数组：先放文字，再依次放 `[图片 #1]` 标签和 `image_url`（base64 data URL）。
- 用户的话里保留占位符，AI 能对上「哪句话说的是哪张图」。
- 支持 PNG / JPEG / GIF / WebP，单张最大 20 MB，按文件内容识别格式，不看扩展名。
- 带图片时如果接口不接受 JSON 模式（HTTP 400），会去掉 JSON 模式重试一次，输出照样严格校验。
- 发送前检查文字里有没有疑似密钥（`sk-…`、令牌、私钥、「密码：…」、长串字母数字混合）；有就先问用户。

## AI 返回格式

```json
{"reply": "记下了", "ops": [...], "skipped": [{"id": 3, "reason": "已有，截止时间相同"}], "ask": null}
```

反问时：

```json
{"reply": "", "ops": [], "ask": {"question": "是哪一个？", "options": ["2. 作业 a", "5. 作业 b"]}}
```

你选的选项会以「我的回答：…」发回 AI，再出结果。

`skipped` 是 AI 判断「已经有了、没再添加」的条目，只用于显示；编号不存在的会被忽略，不触发重试。

## 去重（两道）

1. **AI 判断**（能认出换了说法的同一件事）：同一件事有新信息 → `update` 原条目；没有新信息 → 写进 `skipped`。
2. **程序兜底**（`ops.dedupe`，只拦明显的）：新增的条目与「现有条目 / 30 天内归档 / 同一批里前面的条目」比较，同时满足以下条件就不添加，并显示 `≈ 已存在`：
   - 类型相同（任务对任务，笔记对笔记）；
   - 去掉空格标点后文字相似度 ≥ 0.85，且其中的数字、英文字母完全一致（「作业4」≠「作业5」）；
   - 截止日期相同，或有一方没写（截止不同的同名事，比如每周周报，不算重复）。
   - AI 给 `add` 加上 `"allow_duplicate": true` 可以跳过兜底（只在用户明说「再加一个」时）。

全部被去重时不拍快照、不写文件。

## 允许的操作

| op | 字段 | 说明 |
| --- | --- | --- |
| `add` | `notebook` `text` `kind`(task/note) `due` `priority`(1-3) `state` `allow_duplicate` | 新增；记事本不存在就新建 |
| `update` | `id` + 任意：`text` `due`(null=清除) `priority` `state` `notebook` `kind` | 修改；改 `notebook` = 移动 |
| `delete` | `id` | 删除（仍可 `jk undo`） |
| `rename_notebook` | `from` `to` | 改名；`to` 已存在 = 合并 |

校验规则（`src/jk/ops.py`）：编号必须存在、记事本名 1-20 字、时间必须是规定格式、优先级只能 1/2/3、状态只能 todo/doing/done。

## AI 的行为准则（摘要）

- 相对时间按日历换算；只说钟点取最近的将来；1-6 点默认下午。
- 文字简洁、动词开头，不含时间。
- 优先放进已有记事本，不合适才新建 2-4 字的类别名。
- 只改你提到的条目；说「整理」才批量调整。
- 多个可能或找不到 → 反问。
- 纯提问 → 只回答，不改动。

## 隐私

每次 `jk a` 会把**全部未归档条目**、最近 30 天归档的文字、以及你粘贴的文字和图片发给 `JK_BASE_URL`。不要在记事本里写密码。
粘贴内容先存进 `$JK_HOME/pastes/`，发送结束就删除；程序异常退出留下的，超过一天会在下次打开输入框时清理。
